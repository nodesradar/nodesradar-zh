## 常见问题

**免费节点雷达是什么？**

免费节点雷达每天从公开渠道收集别人分享的免费节点（VLESS、VMess、Shadowsocks、SSR、Trojan、Hysteria2、TUIC），去掉重复和无效的，逐个测试，按国家地区命名，把能用的节点整理成可以直接导入的订阅。

**我该用哪个订阅？**

Clash Verge Rev、Clash Party、FlClash、Clash Meta for Android、Stash 用 Clash 订阅；v2rayN、v2rayNG、小火箭、NekoBox、Hiddify、Karing 用 V2Ray 通用订阅；sing-box 官方客户端用 sing-box 订阅。

**怎么添加订阅？**

复制订阅地址，打开客户端，找到“订阅”或“配置”，新建后粘贴地址并更新。Clash 系客户端、v2rayNG 和 sing-box 也可以在本页点“一键导入”。

**多久更新一次？**

每 6 小时更新一次，分别在北京时间 6:17、12:17、18:17 和 0:17 开始，大约半小时后完成。建议在客户端里把订阅设为每 6 小时自动更新。

**为什么有些节点我用不了？**

免费节点经常失效，而且测试是在境外服务器上做的，在那边能用的节点在国内可能被封。用配置里的“自动选择”分组，或者在客户端里测一下延迟，挑能用的节点。

**用免费节点安全吗？**

节点的运营方能看到你的流量去了哪里。HTTPS 网站的内容仍然是加密的，但不要通过免费节点登录银行、邮箱等重要账号。
